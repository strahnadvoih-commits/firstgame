# Весёлая ферма — Merge Valley

Мобильный HTML5-прототип merge-фермы: строй постройки, объединяй одинаковые пары, выполняй заказы и качай ферму. Один файл `index.html`, без сборки — просто открой в браузере.

## Что внутри

- **Стартовый экран** — логотип, «Играть»/«Продолжить» (в зависимости от наличия сохранения), «Настройки», «Об игре», «Начать заново».
- **Обучение** — 6 шагов с персонажем-наставником Дедом Матвеем, доступно повторно в любой момент через меню ☰.
- **Диалоги NPC** — короткие реплики персонажей (наставник, торговка, механик, садовница) при первой постройке, первом объединении, первом заказе, первом улучшении, первом расширении, заполнении всех клеток и первом повышении уровня фермы.
- **Меню ☰** — обучение, альбом построек, статистика, расширение территории, сохранение, настройки, информация об игре.
- **Настройки** — переключатель звуковых эффектов (Web Audio, без внешних файлов), сброс прогресса.
- **Игровой цикл** — строительство, merge-объединение, заказы, улучшения, ежедневная награда, сундук фермера, офлайн-доход, прогресс уровня фермы.

## Технические заметки

- Один файл, без зависимостей: HTML + CSS + SVG-иконки + JS, сохранение в `localStorage`.
- Исправлен баг исходной версии: скрипт с обработчиками меню/обучения был расположен раньше DOM-узлов этих экранов, из-за чего `☰` не открывал меню, а обучение никогда не запускалось. Скрипт перенесён в конец `<body>`.
- Перед публикацией в Yandex Games нужны: официальный SDK (`window.YandexGames` — заглушка уже есть), cloud save, rewarded-реклама, музыка/озвучка диалогов, финальная балансировка экономики.

## Запуск

Открой `index.html` в браузере, либо локально:

```
python3 -m http.server 8080
```

и перейди на `http://localhost:8080/`.
