# Весёлая ферма — Merge Valley

Мобильный HTML5-прототип merge-фермы: строй постройки, объединяй одинаковые пары, выполняй заказы и качай ферму. Один файл `index.html`, без сборки — просто открой в браузере.

## Что внутри

- **Стартовый экран** — логотип, «Играть»/«Продолжить» (в зависимости от наличия сохранения), «Настройки», «Об игре», «Начать заново».
- **Обучение** — 7 шагов с персонажем-наставником Дедом Матвеем, доступно повторно в любой момент через меню ☰.
- **Диалоги NPC** — короткие реплики персонажей (наставник, торговка, механик, садовница) при первой постройке, первом объединении, первом заказе, первом улучшении, расширении клеток, открытии района на карте, заполнении всех клеток и при каждом повышении уровня фермы.
- **Заказы (обновляемые)** — всегда 3 активных заказа из 6 типов (построить/заработать/объединить/продать/улучшить/открыть сундук). После выполнения заказ автоматически заменяется новым, сложнее и с большей наградой. Не нравится задание — его можно заменить вручную за 15 🪙.
- **Система прокачки фермы** — прогрессивная шкала уровней (порог опыта растёт с каждым уровнем, а не фиксированные 500 XP), 9 именных титулов фермы, награда монетами и диалог наставника при каждом повышении уровня.
- **Карта долины** — отдельная сцена с 9 районами на пути, связанными пунктирной линией. Метка «Ты здесь» показывает текущее положение; районы открываются по достижении нужного уровня фермы и дают постоянный бонус к доходу, который складывается с бонусами улучшений.
- **Таблица лидеров** — сравнение фермы игрока с ботами-фермерами (локально, без сервера), с кнопкой обновления рейтинга.
- **Меню ☰** — обучение, карта долины, таблица лидеров, альбом построек, статистика, расширение клеток поля, сохранение, настройки, информация об игре.
- **Настройки** — переключатель звуковых эффектов (Web Audio, без внешних файлов), сброс прогресса.
- **Игровой цикл** — строительство, merge-объединение, заказы, улучшения, ежедневная награда, сундук фермера, офлайн-доход.
- **Yandex Games SDK** — реальная интеграция (не заглушка): `LoadingAPI.ready()`, `GameplayAPI.start()/stop()`, облачное сохранение через `player.getData()/setData()` с фолбэком на `localStorage`, rewarded-реклама (сундук фермера можно удвоить, посмотрев видео) и interstitial-реклама на крупных вехах (открытие района на карте).
- **Погода дня (хук/сеттинг)** — каждый календарный день на ферме своя погода из 6 вариантов («Солнечно», «Дождливо», «Ветрено», «Рыночный день», «Сбор урожая», «Тихий день»), временно усиливающая доход конкретных построек. Меняется каждый день у всех игроков одинаково (считается от даты, без сервера) — причина заходить в игру снова.
- **Музыка** — процедурный эмбиент-луп на Web Audio (без внешних файлов), отдельный тумблер в настройках; звуковые эффекты стали многоголосыми (аккорды вместо одиночных пиков).
- **Пересчитан баланс merge-цикла** — раньше доход постройки рос строго линейно с уровнем (2 объекта уровня 1 = 1 объект уровня 2 по доходу), из-за чего объединение экономило только клетки. Теперь доход растёт быстрее уровня (прогрессивная кривая), и объединение — реальный источник роста, а не только экономии места.
- **Сбор и продажа урожая** — новая вкладка «🌾 Урожай». Каждая занятая клетка периодически «созревает» (над ней загорается иконка культуры, сама клетка светится) — тапни, чтобы собрать. Урожай копится в инвентаре по 6 видам культур (зерно, молоко, мука, яблоки, шерсть, выпечка — по одному на тип постройки) и продаётся за монеты на вкладке «Урожай», отдельно от пассивного дохода. Погода дня напрямую влияет на размер урожая при сборе (тот же множитель, что усиливает доход). Есть свой тип заказа «Собери N урожая» и вклад в очки таблицы лидеров.
- **Выбор постройки и лимит на тип** — тап по пустой клетке (или кнопка «Построить») открывает выбор из доступных типов построек вместо случайного выбора. У каждого типа свой лимит на ферме (`max` в описании построек), который теперь реально соблюдается — раньше поле было заведено в данных, но нигде не проверялось.
- **Новые постройки открываются с уровнем фермы** — раньше доступность типа зависела от того, сколько всего уже построено (косвенный счётчик, не связанный с реальной прогрессией). Теперь у каждого типа есть `unlockLevel`: поле и ферма — с 1 уровня, мельница — со 2, сад — с 3, амбар — с 5, кафе — с 7. В выборе построек и в «Альбоме» ещё не открытые типы показаны как «???» с указанием нужного уровня; при повышении уровня, на котором открывается новый тип, наставник упоминает его по имени в диалоге.
- **Свои диалоги подтверждения** — сброс прогресса (со стартового экрана, из настроек и с фермы) больше не полагается на нативный `confirm()` браузера. Теперь это часть интерфейса игры (тот же компонент модалки), что надёжно работает в любом окружении — включая встроенные браузеры мессенджеров и превью, которые часто блокируют или молча отменяют системные диалоги.

## Технические заметки

- Один файл, без зависимостей: HTML + CSS + SVG-иконки + JS, сохранение в `localStorage` (+ облако на платформе).
- Исправлен баг исходной версии: скрипт с обработчиками меню/обучения был расположен раньше DOM-узлов этих экранов, из-за чего `☰` не открывал меню, а обучение никогда не запускалось. Скрипт перенесён в конец `<body>`.
- Сохранения прежних версий мигрируют автоматически: недостающие поля (заказы, карта, счётчики, уровень, настройки) достраиваются при загрузке без потери прогресса и без ретроактивного спама диалогов о повышении уровня. Заодно исправлен скрытый баг слияния сохранений: вложенные объекты (`settings`, `upgrades`, `dialogsShown`, `mapClaimed`) мутировали дефолтный объект до того, как из него брались недостающие ключи — новые поля (например, `music`) у старых сохранений просто не появлялись. Теперь дефолты снимаются снимком до слияния.
- Таблица лидеров — локальная симуляция (боты хранятся в `localStorage` игрока), это явно указано в самом интерфейсе, чтобы не выдавать её за настоящий онлайн-рейтинг. Реальный Leaderboards API пока не подключён.
- SDK подключается через `<script src="https://yandex.ru/games/sdk/v2">` и грузится асинхронно: вне платформы Яндекс Игр (локальный запуск, другой хостинг) `window.YaGames` просто отсутствует, и игра прозрачно работает в автономном режиме — без рекламы и с сохранением только в `localStorage`. Статус подключения виден в разделе «Об игре» (☰ → Об игре → «Яндекс SDK»).
- Облачное сохранение подтягивается только на «чистом» браузере без локального сохранения (сценарий «зашёл с нового устройства») — если локальный прогресс уже есть, он не перезатирается автоматически, чтобы не потерять более свежие локальные данные.
- Музыка стартует по нажатию «Играть» на стартовом экране — это осознанный пользовательский жест, без которого браузеры блокируют автовоспроизведение звука.
- Перед публикацией в Yandex Games ещё нужны: иконка/обложка/скриншоты и описание для карточки в каталоге, анкета возрастного рейтинга, дальнейшая тонкая настройка экономики по метрикам удержания, и, по желанию, реальный Leaderboards API вместо локальной симуляции. Маркетинг и привлечение аудитории — вне зоны того, что решается кодом.

## Запуск

Открой `index.html` в браузере, либо локально:

```
python3 -m http.server 8080
```

и перейди на `http://localhost:8080/`.
