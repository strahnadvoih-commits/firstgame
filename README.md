# Весёлая ферма — Merge Valley

Мобильный HTML5-прототип merge-фермы: строй постройки, объединяй одинаковые пары, выполняй заказы и качай ферму. Один файл `index.html`, без сборки — просто открой в браузере.

## Что внутри

- **Стартовый экран** — логотип, «Играть»/«Продолжить» (в зависимости от наличия сохранения), «Настройки», «Об игре», «Начать заново».
- **Обучение** — 7 шагов с персонажем-наставником Дедом Матвеем, доступно повторно в любой момент через меню ☰.
- **Диалоги NPC** — короткие реплики персонажей (наставник, торговка, механик, садовница) при первой постройке, первом объединении, первом заказе, первом улучшении, расширении клеток, открытии района на карте, заполнении всех клеток и при каждом повышении уровня фермы.
- **Заказы (обновляемые)** — всегда 3 активных заказа из 6 типов (построить/заработать/объединить/продать/улучшить/открыть сундук). После выполнения заказ автоматически заменяется новым, сложнее и с большей наградой. Не нравится задание — его можно заменить вручную за 15 🪙.
- **Система прокачки фермы** — прогрессивная шкала уровней (порог опыта растёт с каждым уровнем, а не фиксированные 500 XP), 9 именных титулов фермы, награда монетами и диалог наставника при каждом повышении уровня.
- **Карта долины** — отдельная сцена с 9 районами на пути, связанными пунктирной линией. Метка «Ты здесь» показывает текущее положение; районы открываются по достижении нужного уровня фермы и дают постоянный бонус к доходу, который складывается с бонусами улучшений.
- **Таблица лидеров** — сравнение фермы игрока с ботами-фермерами (локально, без сервера), с кнопкой обновления рейтинга.
- **Меню ☰** — обучение, карта долины, таблица лидеров, альбом построек, статистика, расширение клеток поля, сохранение, настройки, информация об игре.
- **Настройки** — переключатель звуковых эффектов (Web Audio, без внешних файлов), сброс прогресса.
- **Игровой цикл** — строительство, merge-объединение, заказы, улучшения, ежедневная награда, сундук фермера, офлайн-доход.
- **Yandex Games SDK** — реальная интеграция (не заглушка): `LoadingAPI.ready()`, `GameplayAPI.start()/stop()`, облачное сохранение через `player.getData()/setData()` с фолбэком на `localStorage`, rewarded-реклама (сундук фермера можно удвоить, посмотрев видео) и interstitial-реклама на крупных вехах (открытие района на карте).

## Технические заметки

- Один файл, без зависимостей: HTML + CSS + SVG-иконки + JS, сохранение в `localStorage` (+ облако на платформе).
- Исправлен баг исходной версии: скрипт с обработчиками меню/обучения был расположен раньше DOM-узлов этих экранов, из-за чего `☰` не открывал меню, а обучение никогда не запускалось. Скрипт перенесён в конец `<body>`.
- Сохранения прежних версий мигрируют автоматически: недостающие поля (заказы, карта, счётчики, уровень) достраиваются при загрузке без потери прогресса и без ретроактивного спама диалогов о повышении уровня.
- Таблица лидеров — локальная симуляция (боты хранятся в `localStorage` игрока), это явно указано в самом интерфейсе, чтобы не выдавать её за настоящий онлайн-рейтинг. Реальный Leaderboards API пока не подключён.
- SDK подключается через `<script src="https://yandex.ru/games/sdk/v2">` и грузится асинхронно: вне платформы Яндекс Игр (локальный запуск, другой хостинг) `window.YaGames` просто отсутствует, и игра прозрачно работает в автономном режиме — без рекламы и с сохранением только в `localStorage`. Статус подключения виден в разделе «Об игре» (☰ → Об игре → «Яндекс SDK»).
- Облачное сохранение подтягивается только на «чистом» браузере без локального сохранения (сценарий «зашёл с нового устройства») — если локальный прогресс уже есть, он не перезатирается автоматически, чтобы не потерять более свежие локальные данные.
- Перед публикацией в Yandex Games ещё нужны: иконка/обложка/скриншоты и описание для карточки в каталоге, анкета возрастного рейтинга, полноценная балансировка экономики, музыка/озвучка диалогов, и, по желанию, реальный Leaderboards API вместо локальной симуляции.

## Запуск

Открой `index.html` в браузере, либо локально:

```
python3 -m http.server 8080
```

и перейди на `http://localhost:8080/`.
